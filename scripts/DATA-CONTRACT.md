# Public comparison data contract (schemaVersion 1)

`public/data/crime.json` is generated by `python scripts/refresh_data.py`.

- `coverage`: `{start, end, label, frequency: "quarterly", sourcePublishedAt}`. Start/end are ISO dates of the latest rolling 12 months.
- `generatedAt`: ISO UTC timestamp of the last successful changed data build. Identical source files do not change it.
- `unit`: `"offences per 1,000 residents"`.
- `categories`: `{id, label, description, group, ratePer, nationalIncludesBtp}` entries. `group` is `Main offence groups`, `Detailed offence groups` or `Knife and firearm offences`. `ratePer` is a **presentation** denominator: 100,000 for homicide, unlawful driving, knife-enabled crime and firearm offences; 1,000 otherwise. **Every stored rate, including historical rates, remains per 1,000 residents.** Multiply stored rates by `ratePer / 1000` for display. Stored rates retain eight decimal places to avoid double rounding when converted to per 100,000; the UI rounds for presentation.
- `areas`: `{id, code, name, type, regionId, population, populationYear, comparisonEligible, metrics, quality}`. IDs are ONS geography codes. Types are `force`, `region`, `nation`. Wales is included in the region comparison. England and Wales baseline is `K04000001`.
- `metrics[categoryId]`: `{count, rate, previousCount, changePercent, history}` with optional `changeSuppressedReason: string`. `count` is latest rolling-year offences; change is the **published** ONS percentage change on the previous rolling year. Suppressed/unavailable source changes remain `null` even when a percentage could be reconstructed from the counts. Rate is per 1,000 residents from actual ONS mid-year estimates. `history`: `[{periodEnd, count, rate}]` of published rolling-year values.
- Unsupported or suppressed values use JSON `null`, never zero. City of London is present but `comparisonEligible=false` and `rate=null` because resident-based comparisons are misleading there.
- `sources`: `{id, title, url, publishedAt}`. Exact retrieved file URLs and SHA-256 hashes are in `source-manifest.json`.

The 25 category IDs are `all-crime`, `violence`, `sexual-offences`, `robbery`, `burglary`, `vehicle-crime`, `theft-from-person`, `shoplifting`, `criminal-damage`, `drug-offences`, `weapons`, `public-order`, `homicide`, `unlawful-driving`, `violence-with-injury`, `violence-without-injury`, `stalking-harassment`, `theft`, `residential-burglary`, `non-residential-burglary`, `bicycle-theft`, `other-theft`, `miscellaneous`, `knife-enabled`, `firearms`.

The 23 standard measures use current/previous-year counts from ONS P1/P4, with published P2 changes and suppressions preserved. Their 13-point histories use the latest revised Home Office quarterly file, each point summing four quarters. Every current and previous-year count is reconciled across those two official sources before publication.

Knife-enabled totals come from P6 and reconcile against current P5 totals and exact-population P7 current rates. Firearm offences come from P8. Their histories retain **actual published dates**: annual observations followed by the latest equivalent rolling years. The current snapshot has 16 knife points from March 2011 to June 2026 and 17 firearm points from March 2010 to June 2026. Do not manufacture quarters or space these as quarterly observations. Where this population source does not extend far enough back, historical rates are `null` while actual historical counts remain visible. Older knife/firearm observations have recording comparability warnings; read category descriptions and affected-area notes.

Main groups, their detailed components and weapon-enabled measures **overlap**. They must not be summed across the full category list. For a disjoint crime composition use the nine `Main offence groups` excluding `all-crime`. Violence has five children; theft has six children; burglary has two children. The validator checks these partitions independently.

Fraud is excluded throughout. Anti-social behaviour is not counted as crime. The national baseline includes British Transport Police **except firearm offences**, whose collection excludes it (`nationalIncludesBtp: false`). All regional and territorial-force comparisons exclude BTP. The validator checks national coverage separately for each category and verifies current, previous-year and historical regional totals against their constituent forces.

`source-manifest.json` includes `pipelineVersion` so a changed transformation can rebuild without an upstream source change. Increment that version when changing transformations. No extra source download or Python dependency is required for the 25 measures.

The separate Police.uk `monthly.json` retains 14 mapping categories. Each metric also has `monthlyCounts: [{month: "YYYY-MM", count: number | null}]`, currently 24 calendar months. Each area has `monthlyCoverage: {currentComplete, previousComplete, missingForceMonths}`. The UI pairs each latest-year month with the same calendar month one year earlier; absent months remain null and zero is a valid reported count. Percentages against a missing or zero earlier count are unavailable. Raw monthly counts and rolling-year totals must be labelled separately. Monthly category definitions must not be spliced into the official series.

Profile CSVs retain all categories and actual observation dates, always label stored rates per 1,000, and distinguish the series' publication frequency from observation type. Only explicitly published current annual percentage changes are exported; historical annual changes are not inferred. Source-suppressed current changes stay blank, with their suppression reason. Raw monthly year-on-year changes are calculated from the matching calendar months.
