# Public comparison data contract (schemaVersion 1)

`public/data/crime.json` is generated by `python scripts/refresh_data.py`.

- `coverage`: `{start, end, label, frequency: "quarterly", sourcePublishedAt}`. Start/end are ISO dates of the latest rolling 12 months.
- `generatedAt`: ISO UTC timestamp of the last successful changed data build. Identical source files do not change it.
- `unit`: `"offences per 1,000 residents"`.
- `categories`: `{id, label, description}` entries.
- `areas`: `{id, code, name, type, regionId, population, populationYear, comparisonEligible, metrics, quality}`. IDs are ONS geography codes. Types are `force`, `region`, `nation`. Wales is included in the region comparison. England and Wales baseline is `K04000001`.
- `metrics[categoryId]`: `{count, rate, previousCount, changePercent, history}`. `count` is latest rolling-year offences; change is offence-count change on the previous rolling year. Rate is per 1,000 residents from actual ONS mid-year estimates. `history`: `[{periodEnd, count, rate}]` of rolling-year values.
- Unsupported or suppressed values use JSON `null`, never zero. City of London is present but `comparisonEligible=false` and `rate=null` because resident-based comparisons are misleading there.
- `sources`: `{id, title, url, publishedAt}`. Exact retrieved file URLs and SHA-256 hashes are in `source-manifest.json`.

Category IDs: `all-crime`, `violence`, `sexual-offences`, `robbery`, `burglary`, `vehicle-crime`, `theft-from-person`, `shoplifting`, `criminal-damage`, `drug-offences`, `weapons`, `public-order`.

Latest and previous-year comparison counts come from the same current ONS Police Force Area workbook. History uses the latest revised Home Office quarterly open-data file, with each point summing four quarters. Fraud is excluded throughout. Anti-social behaviour is not counted as crime. The national baseline includes British Transport Police; regional and force comparisons exclude it.
